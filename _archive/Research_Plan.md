# Multimodal Skin Disease Classification System

## 1. Research Title

Multimodal Skin Disease Classification System Using Skin Images and Clinical Metadata


---

# 2. Research Background

Skin diseases are common healthcare problems.
Traditional diagnosis requires expert dermatologists.

Deep learning based skin image classification has shown promising results.

However, image-only models ignore important clinical information such as:

- patient age
- gender
- anatomical location
- symptoms
- medical history


Therefore, this research focuses on combining visual and clinical information through multimodal learning.


---

# 3. Research Problem

Existing approaches mainly focus on:

- image-only classification
- limited metadata usage
- weak generalization
- lack of external validation


Research question:

Can combining skin images and clinical metadata improve disease classification performance and reliability?


---

# 4. Research Objectives


## Primary Objective

Develop a multimodal skin disease classification framework using image and clinical metadata.


## Secondary Objectives

1. Analyze existing image-based methods.

2. Develop strong image baseline models.

3. Develop metadata-based models.

4. Design multimodal fusion approach.

5. Evaluate performance using external datasets.

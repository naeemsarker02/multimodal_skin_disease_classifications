# ISIC Archive 1 Processed Dataset Description

Generated: 2026-07-08 00:06:12

## Source

Raw data: `data/raw/ISIC_Archive_1/` (untouched, read-only).
No metadata.csv ships with this archive - class labels come from the folder structure (`Train|Test/<class_label>/*.jpg`). Images are **not copied**; `image_path` points back to the original file.

## Data-Quality Exclusion

The audit (`reports/ISIC_Archive_1/02_duplicate_filename_label_conflicts.csv`) found 310 images filed under two different, conflicting class labels (the same filename appearing under e.g. both `melanoma` and `seborrheic keratosis`, systematically - 78 and 77 occurrences respectively for the two conflicting pairs). These images were **excluded** from the cleaned dataset rather than arbitrarily assigned to one label, since their true class cannot be determined from this archive alone.

## Label Standardization

See `label_mapping.csv`. Uses the taxonomy shared with ISIC Archive 2 (`src/data_cleaning/common_label_mapping.py`) so diseases common to both archives (and to PAD-UFES-20/HAM10000 where applicable) use identical names.

## Train / Validation / Test Split

- No lesion or patient identifier exists in this archive - each image is treated as independent.
- The archive's own **Test** split is kept exactly as provided (final held-out set, untouched). A validation set is carved out of the archive's **Train** split only (15% of Train, stratified by disease_label).
- Random seed: 42 (fixed, for reproducibility)
- Total images: 2047

- **train**: 1655 images
- **val**: 292 images
- **test**: 100 images

No filename appears in more than one split (verified in `split_quality_report.csv`).

## Cross-Dataset External-Validation Exclusions (2026-07-08)

`docs/Dataset_Preparation_Final_Report.md` §6 found that this archive shares
1,362 of its 2,047 images (66.5%) with HAM10000, because ISIC Archive 1 was
itself bulk-exported from the same underlying ISIC image pool that HAM10000
draws from. Since 41% of those shared images land in different train/val/test
splits between the two datasets when split independently, using this archive
in full as "external validation" against a HAM10000-trained model would
silently include images the model already saw in training.

**Decision (fix (b) — restrict external-validation claims, see
`Project_Tracking.md` for full rationale):** rather than re-splitting all
three datasets globally, the 1,362 overlapping `image_id`s are excluded from
this archive whenever it is used as external validation against a
HAM10000-trained model. This archive's own train/val/test files
(`metadata_train.csv`, `metadata_val.csv`, `metadata_test.csv`) and split
ratios are **unchanged** — the exclusion applies only at evaluation time, via
`data/processed/ISIC_Archive_1/external_validation_exclusions.csv` (the list
of excluded `image_id`s, generated by
`src/data_cleaning/cross_dataset_leakage_filter.py`).

Row counts:

| | Count |
|---|---|
| Total images in this archive | 2,047 |
| Overlapping with HAM10000 (excluded before HAM10000-external-validation use) | 1,362 |
| Remaining, valid for external validation against a HAM10000-trained model | 685 |

This exclusion is **not needed** when this archive is used for its own
internal train/val/test evaluation, or as external validation against a
model trained only on PAD-UFES-20 (which has zero image overlap with any
other dataset).

**Also documented (no action needed):** of the 1,673 images this archive
shares with ISIC Archive 2, 3 have disagreeing `disease_label` values between
the two archives (`ISIC_0028619`: Nevus here vs. Actinic Keratosis in Archive
2; `ISIC_0011126` and `ISIC_0011118`: Seborrheic Keratosis here vs. Melanoma
in Archive 2). This is a pre-existing annotation disagreement inherited from
the source archives, not introduced by this project's cleaning. Negligible
volume (0.18% of the shared images); keep in mind if these specific images
are ever used in a merged evaluation pool.

## Known Limitations

- Test set is small and imbalanced (e.g. only 3 seborrheic keratosis and 3 vascular lesion images).
- No clinical/demographic metadata (unlike PAD-UFES-20) - image + class label only.
- No patient identifier - cannot rule out the same patient/lesion contributing images to both Train and Test.
